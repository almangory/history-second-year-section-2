# 📜 المؤرخ الصغير - تاريخ الصف السادس الابتدائي
> منصة تعليمية تفاعلية شاملة ومطابقة تماماً للمنهج الوطني السوداني (بخت الرضا) مع دعم العمل بدون إنترنت والذكاء الاصطناعي التفاعلي.

---

## 🌟 نظرة عامة على المشروع
**المؤرخ الصغير** هو تطبيق ويب تقدمي (PWA) تعليمي متكامل صُمم خصيصاً لطلاب الصف السادس الابتدائي في السودان، لمساعدتهم على دراسة واستيعاب منهج التاريخ بأسلوب شيق ومبسط ومريح للعين، مع الحفاظ على الهوية الوطنية والتطابق التام مع كتاب التاريخ الصادر عن المركز القومي للمناهج والبحث التربوي (بخت الرضا).

---

## 📚 وحدات المنهج المعتمدة

### 🏰 الوحدة الأولى: تاريخ السودان الحديث (1821م - 1885م)
* **الدرس الأول:** أسباب الغزو التركي المصري على السودان (1821م) وحملتي إسماعيل باشا ومحمد بك الدفتردار ومعركة كورتي.
* **الدرس الثاني:** تأسيس مدينة الخرطوم (1824م) وتطورها كعاصمة سياسية وإدارية.
* **الدرس الثالث:** التعليم والقضاء في العهد التركي المصري وتأسيس أول مدرسة حديثة برئاسة رفاعة رافع الطهطاوي (1853م).
* **الدرس الرابع:** السودان في عهد الخديوي إسماعيل (1863-1879م)، خطوط التلغراف وتطوير ميناء سواكن ومشاريع التوسع.
* **الدرس الخامس:** نهاية الحكم التركي المصري، تعيين غردون باشا، وسياسات الضرائب والاحتكار التي مهدت للثورة المهدية.

### 🕌 الوحدة الثانية: تاريخ الدولة العباسية (132هـ - 656هـ)
* **الدرس الأول:** قيام الدولة العباسية وإعلان الخلافة بالكوفة (132هـ) وأبو العباس السفاح وأبو جعفر المنصور.
* **الدرس الثاني:** الخليفة هارون الرشيد، العصر الذهبي وتأسيس بيت الحكمة وتطور العلاقات الدولية.
* **الدرس الثالث:** بناء مدينة بغداد (مدينة السلام 145هـ) وتصميمها الدائري الفريد كمركز للحضارة.
* **الدرس الرابع:** الحضارة الإسلامية في العصر العباسي، ازدهار العلوم والترجمة والرياضيات والفلك والطب.
* **الدرس الخامس:** نهاية الدولة العباسية وسقوط بغداد على يد المغول بقيادة هولاكو (656هـ / 1258م).

### 🌍 الوحدة الثالثة: الحضارة الإسلامية في إفريقيا
* **الدرس الأول:** دخول الإسلام إلى شمال إفريقيا والمغرب العربي، الأدارسة وتأسيس مدينة فاس وجامع القرويين.
* **الدرس الثاني:** الفتوحات الإسلامية في بلاد المغرب ودور القادة الفاتحين (عقبة بن نافع، موسى بن نصير).
* **الدرس الثالث:** انتشار الإسلام في شرق إفريقيا والساحل السواحيلي، سلطنة كلوة، مقديشو، وزنجبار والتجارة البحرية.
* **الدرس الرابع:** الممالك الإسلامية في غرب إفريقيا (غانا، مالي، سنغاي)، ورحلة الحج التاريخية لمانسا موسى (1324م).

## ✨ المميزات والخصائص الهندسية

* 👁️ **تصميم مريح للعين (Eye-Comfort Themes):**
  * نمط **الورق الطبيعي (Sepia Paper):** ألوان دافئة ومريحة لجلسات المذاكرة الطويلة.
  * نمط **الضوء الهادئ (Soft Light):** تباين ناعم غير مجهد.
  * نمط **الليلي المريح (Deep Slate):** خلفيات كحلية ورمادية هادئة بدلاً من السواد المجهد.
  * تحكم مرن في حجم الخط (عادي، كبير، كبير جداً).

* 🎨 **لوحات تاريخية تعليمية ورسومات توضيحية:**
  * رسومات دقيقة وتاريخية لكل درس تجسد الأحداث والمعارك والشخصيات.
  * عارض صور تفاعلي (Interactive Lightbox) بدقة عالية يتيح للطالب تكبير اللوحات وفحص التفاصيل.

* 🤖 **معلم الذكاء الاصطناعي التفاعلي (المؤرخ الذكي):**
  * مدعوم بنموذج Google Gemini مع تدريب مخصص على وقائع منهج بخت الرضا.
  * إجابات تربوية مبسطة وموجهة للطفل باللهجة السودانية أو العربية الفصحى المبسطة.
  * إمكانية الاستماع الصوتي التفاعلي للدروس (Text-to-Speech).

* 📱 **تصميم موازٍ للهواتف (Mobile-First):**
  * شريط تنقل سفلي ذكي ومريح للأصابع (Navigation Dock).
  * إلغاء التشتت والتكرار في القوائم العلوية على الشاشات الصغيرة.
  * تجاوب كامل مع كافة أحجام الشاشات (الهواتف الذكية، الأجهزة اللوحية، الحواسيب).

* ⚡ **يعمل بالكامل بدون إنترنت (Offline-First PWA):**
  * تخزين محلي ذكي للدروس والأسئلة عبر الـ Service Worker والتخزين المؤقت.
  * إمكانية فتح التطبيق ومتابعة المذاكرة وحل الاختبارات حتى عند انقطاع الإنترنت.

* 🏆 **مركز التحديات والاختبارات التفاعلية:**
  * اختبارات تفاعلية فورية لكل درس.
  * بطاقات تذكر ومراجعة ذكية (Flashcards).
  * بنك أسئلة تدريبية تحضيراً للامتحانات النهائية مع تصحيح فوري وشرح للأسباب.

## 🚀 التشغيل والتطوير محلياً (Run Locally)

### المتطلبات الأساسية:
* **Node.js** (الإصدار 18 فما فوق).
* مدير الحزم `npm`.

### خطوات التشغيل:
```bash
# 1. تثبيت الحزم التبعية
npm install

# 2. إعداد مفتاح واجهة برمجة تطبيقات Gemini في ملف .env
GEMINI_API_KEY="your_api_key_here"

# 3. تشغيل بيئة التطوير
npm run dev
```

### البناء للإنتاج:
```bash
npm run build
```

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Canvas-Confetti.
* **Build Tool:** Vite, PostCSS.
